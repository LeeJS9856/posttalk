# 스타일 규칙

## 토큰만 쓴다

색과 글자 크기를 컴포넌트에 직접 적지 않는다. `src/constants/colors.ts`와 `typography.ts`의 토큰을 참조한다.
토큰에 없는 값이 필요하면 토큰을 먼저 추가한다.

## 콘셉트는 UI 테마가 아니다

콘셉트는 생성되는 광고 결과물의 스타일이고 AI 쪽에서 처리한다. 앱 UI는 콘셉트와 무관하게 하나의 디자인을 쓴다.
콘셉트별 테마나 폰트 전환을 만들지 않는다.

## 모바일 전용

- 최소 320px 기준으로 짠다. 데스크톱 레이아웃을 만들지 않는다.
- 높이는 `vh`가 아니라 `svh`를 쓴다. 모바일 브라우저 주소창 때문에 `vh`는 어긋난다.
- 터치 대상은 최소 44px.

## AI 티를 피한다

생성형 도구가 기본값으로 내놓는 조합을 그대로 쓰지 않는다.

- 보라색 그라디언트 배경, 그라디언트 텍스트
- Inter를 비롯한 기본 산세리프 그대로
- 가운데 정렬 히어로 + 카드 3개
- 강조 단어 하나만 색 다르게
- 장식용 `01 / 02 / 03` 번호
- 크림색 + 테라코타, 거의 검정 + 형광 연두 같은 "세련돼 보이는" 기본값

의심스러우면 `avoid-ai-design` 스킬로 점검한다.

## 하지 말 것

- CSS-in-JS 바깥에서 전역 클래스를 만들지 않는다. 전역 스타일은 `GlobalStyle` 한 곳이다.
- `!important`를 쓰지 않는다.
- 인라인 `style` 속성으로 레이아웃을 잡지 않는다.
